# python-weather
Python app to get the weather forecast.
This started as a rewrite for my [AWS weather application](https://github.com/fred-storm/aws_weather_forecast) in Python.  My goal now is to transform it into its own standalone application that can be hosted in another manner.  I may make this a container service; I am still undecided.

## Current functions

- Gets a 7-day (14-period) forecast for the selected area (hard-coded as a variable at this time) and displays the detailed forecast paragraph
- Fetches the current day's CONUS weather maps showing fronts and expected weather.

## Technologies

- Python
- APIs
- Web Scraping
